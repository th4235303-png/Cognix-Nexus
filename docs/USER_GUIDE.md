# Cognix Nexus — User Guide

## Core workflow
1. Sign in.
2. Add a source/book.
3. Wait for processing to reach a durable state.
4. Review extracted knowledge and evidence.
5. Use retrieval/RAG with source citations.
6. Approve only content you have reviewed.

## Reading and knowledge
Reading progress is durable and can resume from checkpoints. Derived knowledge should retain its source lineage.

## Document review
Future Document Assistant enhancements include document-type classification, OCR review, low-confidence highlighting, domain disclaimers and explicit Inbox → Processing → Review → Approved → Indexed → Archived → Deleted lifecycle states.

## Language learning
The roadmap includes JP/KR support, parallel text, grammar explanations, pronunciation aids, TTS, writing correction, role-play, quizzes and CEFR/JLPT/TOPIK mapping. These are roadmap scope, not current production claims.

## Privacy
Do not paste secrets into chat. Vault/privacy-sensitive capabilities remain owner-scoped and fail closed. Export/delete and production recovery are release gates.
